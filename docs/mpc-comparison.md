# TDAS와 MPC 비교 (2026-11)

TDAS의 장점이 비용인지, 예측이 덜 필요하다는 데 있는지를 확인한 기록입니다. MPC는 원본 [`MPC.py`](../MPC.py)를 그대로 실행합니다. [`experiments/run_mpc.py`](../experiments/run_mpc.py)는 예측 구간·예측 노이즈·데이터만 바꾸고, 결과로 나온 시간별 구매량을 TDAS 연간 rollout과 같은 규칙(같은 요금, 일별 DC, 초기 배터리 1.5 kWh)으로 다시 계산합니다. 모든 실행에서 수요 미충족, 충전율 초과, 버려진 구매는 0이었습니다.

## 비교 대상

| 이름 | 미래 정보 | 비고 |
|---|---|---|
| Greedy | 없음 | 수요만 충족 |
| TDAS | 2시간 앞 부하·PV를 정확히 앎 (Tf=2) | 1월 30일로 학습, 검증 기준 최적 checkpoint |
| MPC-2 / MPC-6 | 2 / 6시간 앞을 정확히 앎 | |
| MPC-24 | 24시간 앞을 정확히 앎 | 논문 비교 대상 |
| MPC-24n | 24시간 예측에 노이즈 | `MPC.py` 방식: k시간 앞 표준편차 = σ·k/24 (σ = 24시간 앞 표준편차, 논문 0.6 kWh) |

## 1. 논문 시나리오 (연간 비용 $, 시나리오 3 Seoul / 4 Oxnard)

| | 시나리오 3 | 시나리오 4 |
|---|---|---|
| Greedy | 332.9 | 314.3 |
| MPC-2 | 337.2 | 333.8 |
| MPC-6 | 274.3 | 263.5 |
| **TDAS** 논문 설정 30만 일 (seed 3) | **225.2** | **225.1** |
| TDAS `tuned` 6000일 (seed 3) | 231.6 | 224.4 |
| MPC-24n σ=0.6 (seed 3) | 224.1 | 224.0 |
| MPC-24n σ=1.2 (seed 2) | 234.5 | 235.4 |
| MPC-24n σ=2.4 (seed 2) | 290.2 | 293.8 |
| MPC-24 | 215.3 (논문 214.5) | 213.8 (논문 211.3) |

- **MPC-24는 논문 값을 0.4~1.2% 이내로 재현합니다.** 예측이 완벽하면 MPC가 TDAS보다 4~5% 쌉니다.
- **같은 미래 정보(2시간)를 주면 MPC는 Greedy와 같은 수준입니다(337 vs 333).** TDAS는 같은 정보로 32% 절감합니다. TDAS의 성능은 예보가 아니라, 학습으로 익힌 하루 패턴(언제 싸게 사 두고 피크를 낮출지)에서 나옵니다. MPC가 TDAS만큼 하려면 6시간 예측으로도 부족하고 24시간 예측이 필요합니다.
- **24시간 예측 오차가 σ≈0.6 kWh면 MPC와 TDAS가 같아지고, σ=1.2 kWh면 TDAS가 낫습니다.** σ=2.4 kWh에서는 MPC가 TDAS보다 29% 비쌉니다. 가구 부하가 시간당 최대 2 kWh(0.5배 규모)인 점을 생각하면, 단일 가구의 하루 앞 예측에서 σ 1 kWh 안팎의 오차는 비현실적인 가정이 아닙니다(실제 예측기의 오차는 측정하지 않았습니다).

- **새 가구에서는 TDAS가 MPC-24보다 7~20% 비쌉니다.** PV가 많아 연간 비용 자체가 작은 Ausgrid 두 가구는 상대 차이가 37%, 59%로 더 큽니다. 논문 데이터에서 본 4~5%보다 차이가 큽니다.
- 차이가 큰 곳은 **1월 학습과 연중 패턴이 많이 다른 곳**입니다. 여름 냉방이 큰 Dallas·Phoenix, 겨울 일조가 거의 없는 Fairbanks, 계절에 따라 PV가 크게 바뀌는 Ausgrid 가구가 그렇습니다. 논문 데이터(Seoul, Oxnard)는 TDAS에 유리한 경우였습니다.
- σ=0.6의 MPC-24n과 비교해도 TDAS가 1~16% 비쌉니다. 앞의 결과와 합치면, TDAS가 MPC보다 나으려면 24시간 예측 오차가 σ≈1 kWh 이상이어야 합니다.

## 결론

- TDAS의 장점은 **비용이 아니라 예측이 필요 없다는 것**입니다. 2시간 앞 정보만으로, 24시간을 완벽히 예측하는 MPC보다 4~20% 비싼 수준까지 갑니다(PV가 많은 가구 제외). 같은 정보를 가진 MPC는 Greedy보다 낫지 않습니다.
- 그 밖의 장점: 운영 중 최적화가 없습니다. 이 PC에서 MPC는 1년(8760단계)에 약 2분, 한 단계에 약 14 ms의 IPOPT 계산이 필요합니다. TDAS는 신경망 한 번 계산이면 됩니다(학습에는 가구마다 약 10분).
- 약점: 학습 계절과 다른 계절에서 손해가 큽니다. 새 가구 결과의 차이 대부분은 이 일반화 문제로 보입니다. 다음 실험으로는 연중 데이터를 섞어 학습하거나, 학습할 때 예보에 노이즈를 넣어 보는 것을 생각할 수 있습니다.

## 한계

- MPC-24n의 노이즈는 `MPC.py` 방식(시점마다 독립인 정규분포, 0 아래는 잘라냄)입니다. 실제 예측 오차는 시간적으로 상관되어 있어 MPC에 더 불리할 수도, 유리할 수도 있습니다.
- TDAS 연간 비용은 학습 구간(1월)을 포함합니다(논문과 동일).
- TDAS가 쓰는 2시간 예보는 정확한 값입니다. 예보 오차가 TDAS에 주는 영향은 측정하지 않았습니다. 다만 `MPC.py` 노이즈 모델에서 2시간 앞 표준편차는 σ/12(σ=0.6이면 0.05 kWh)로 작습니다.

## 재현

```bash
.venv/bin/pip install -r requirements-mpc.txt
# 논문 시나리오: MPC-24 / MPC-6 / MPC-2 / MPC-24n
for sc in 3 4; do
  for h in 24 6 2; do .venv/bin/python -m experiments.run_mpc --scenario $sc --horizon $h --output runs/mpc/sc$sc-h$h; done
  for nz in 0.6 1.2 2.4; do for s in 0 1 2; do
    .venv/bin/python -m experiments.run_mpc --scenario $sc --horizon 24 --noise $nz --seed $s --output runs/mpc/sc$sc-h24n$nz-s$s
  done; done
done
# 새 가구 (TDAS는 experiments/plans/scenarios-v1.json)
.venv/bin/python -m experiments.run_mpc --scenario 3 --site tmy3/USA_TX_Dallas-Fort.Worth.Intl.AP.722590_TMY3_BASE --horizon 24 --output runs/mpc/dallas-h24
```

실행 하나는 약 1~2분입니다. 결과는 `<output>/evaluation/controller.json`(MPC 자체 비용, 상태 위반 수, `replay`: TDAS 규칙으로 다시 계산한 TOU·DC·합계와 수요 미충족·충전율 초과·버려진 구매)과 `<output>/history/realized.npz`(시간별 구매량·배터리, 0.1 kWh 단위)에 있습니다. 실행 중에는 대시보드에서도 보입니다.
